## 登記前逐項自問(gate)

- [ ] **命名**:有沒有用人名/團隊名當前綴?名稱裡有沒有版本號?(兩者都不行)
- [ ] **重複**:Skill Bank 裡是不是已經有功能重疊的?
- [ ] **CHANGELOG**:`SKILL.md` 旁邊有沒有 `CHANGELOG.md`?
- [ ] **Owner**:填了真實負責人,沒有留空?
- [ ] **寫入型審核**:會不會寫入外部系統?如果會 → 標 `Active` 前一定要有 Owner review 過。
- [ ] **Scope**:團隊資產(project)還是個人習慣(user)?
- [ ] **外部依賴**:依賴的 MCP / 工具是不是每個環境都已開通?寫進欄位。

> 只要有一項還沒過,狀態就先留 `Draft`,不要標 `Active` 讓別人依賴。
