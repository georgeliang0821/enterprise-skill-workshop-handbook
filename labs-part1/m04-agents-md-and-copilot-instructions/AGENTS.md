# Repo 規則(每次請求自動套用,保持精簡)

- 一律用繁體中文回覆;程式碼註解與 commit message 用英文。
- 提到人名時使用逐字稿或程式碼中出現的實際姓名,不要用職稱代替,也不要編造名字。
- 對「人看的輸出」(會議紀錄、報告、摘要),日期一律用中華民國年:民國YYY年M月D日,例如 2026-01-01 寫成「民國115年1月1日」;無法確定的日期寫「未訂」,不要猜。程式碼、設定檔、API 欄位維持 ISO 8601(YYYY-MM-DD)。
- 不要在骨架程式碼裡補上規格沒有的商業邏輯。
- 需要外部系統(Jira、行事曆)的操作時,先說明你要做什麼、再等使用者確認。
